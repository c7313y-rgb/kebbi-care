# Kebbi 操作ナビ 読み上げ原稿

音声見本を参照した、固定の操作説明です。

## dashboard — 記録と管理状況を、まとめて確認

期間と利用者を選ぶと、表示が変わります。記録の数だけでなく、まだ受け取りの記録がないものや、健康チェックの状況を確認できます。

## records — 必要な記録を、すぐに確認

期間と利用者を選んでください。見たい記録を押すと、話した内容や要約、受け取った職員、健康チェックの結果が表示されます。

## upload — CSVの取り込みは、3ステップ

CSVファイルを選び、保存する施設を確認します。画面の順番に沿って内容をチェックし、問題がなければ取り込んでください。同じCSVをもう一度入れても、同じ記録は増えません。

## preview — 保存前に、照合結果を確認

新しく登録する件数と、追加する件数を確認してください。修正が必要な場合は、CSVを直してもう一度チェックします。問題がなければ、取り込むボタンを押してください。

## drive — DriveのCSVを、そのまま取り込む

初めに、Google DriveのフォルダURLを登録してください。一覧からCSVを選び、内容を確認して取り込みます。新しいファイルを自動で取り込む設定もできます。

## settings — 保存と設定を確認しましょう

ここではマスタの登録、データの保存、接続の設定ができます。バックアップは、すべてのデータを保存するボタンから取得できます。

## pdf — 見やすいサイズで、PDFに

用紙サイズ、向き、文字サイズを選び、プレビューを更新してください。内容を確認したら、PDFを保存できます。印刷するときは、PDFを開いて印刷を押してください。

## saved — 取り込みが完了しました

データを保存しました。ダッシュボードや記録一覧から、取り込んだ内容を確認できます。
