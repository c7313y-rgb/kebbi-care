# Kebbi Care — ジェネラス職員専用

現場測定・データ統合・CSV出力・レポートを一つのアプリ内で利用できます。

公開URL: https://c7313y-rgb.github.io/kebbi-care/

## ログイン

提供職員一覧の専用アカウントでのみ利用できます。一般の新規登録は受け付けません。初回ログインでは12文字以上のパスワードに変更します。管理者の指定は運用責任者の確認後に行います。仮パスワード一覧と実データはこのリポジトリには含まれません。

## 使い方

1. 現場測定で記録し、上部が「保存済み」になるまで待ちます。
2. データ統合画面で測定を取り込みます。旧版や他端末のCSVも取り込めます。
3. 職員間のデータ共有で、自分の測定の共有や共有済み測定の一括取り込みができます。
4. CSV・AI分析用CSV・印刷可能なHTMLレポートを出力します。レポートはブラウザの印刷画面からPDF保存できます。

ログイン・保存には通信が必要です。通信が切れた場合は画面を閉じず、再接続して「今すぐ保存」を押してください。アカウントのデータはサーバーに保存し、端末のlocalStorageやサービスワーカーには個人データ・パスワード・認証トークンを保存しません。同時編集の競合は上書きせず停止します。

## 認証とデータ保護

- GitHub Pagesは個人情報を含まないアプリコードを配信します。
- Supabase東京リージョンが認証とデータ保存を担当します。
- データAPIは毎回、検証済みユーザー、サーバーセッション、有効な職員アカウントを確認します。
- 一般のAuth新規登録はDBトリガーで拒否します。管理APIで発行したアカウントだけを許可します。
- 全テーブルでRLSを有効化し、anon/authenticatedへの直接アクセス権を削除しています。Edge Function内部だけがサービス権限を利用します。
- アカウントの測定・統合データは本人に限定します。共有操作した測定CSVは有効な職員アカウント間で閲覧・統合できます。
- 職員アカウントの停止は次回APIリクエストから反映します。画面は60秒ごとにも有効性を確認します。
- ソースマスターの空欄、原表、役割表は保持します。正式IDの空欄や職員表間の対応は推測して補いません。

## ソース構成

`index.html`、`app.js`、`app.css`: 統合画面・認証・アカウント保存。
`modules/`: 測定、統合、CSV、レポート処理。
`backend/`: データベース定義と認証API。データや秘密鍵は含みません。

Supabaseの公開可能キーはブラウザ接続用で、データアクセス権限を持ちません。サービスキー、配布用パスワード一覧、原Excelは公開禁止です。

## AI連携

統合画面からAI分析用CSVを出力できます。機械判読用の列名、型、単位、出典、品質フラグ、欠損値の扱いは同梱の `AIデータ仕様.json` を参照してください。AIへの自動送信・解析は本アプリでは実行しません。AI用CSVも利用者IDなどを含むため、送信先を確認した上で別途解析してください。

## 保守

`backend/schema.sql` は初期セットアップの再現用です。運用中DBに重複適用しないでください。認証API `backend/api.ts` は外部ライブラリを使用せず、Supabase AuthとPostgRESTを利用します。フロントは同梱のPapaParse 5.4.1 / Chart.js 4.4.1を使用しています。
