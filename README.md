# Kebbi Care — ジェネラス職員専用

現場測定・データ統合・CSV出力・レポートを一つのアプリ内で利用できます。

公開URL: https://c7313y-rgb.github.io/kebbi-care/

## ログイン

今回はジェネラス専用の共通アカウント1件で利用します。個別の47名分アカウントは発行していません。一般の新規登録は受け付けません。初回ログインでは運用責任者が12文字以上のパスワードに変更し、職員に共有します。管理者の指定は運用責任者の確認後に行います。共通アカウントの仮パスワードと実データはこのリポジトリには含まれません。

## 使い方

1. ホームの大きなボタンで「申し送りの時間」「出勤後の情報確認」「職員アンケート」を選びます。
2. 時間の測定は「基本情報 → 時間を測る → 確認・保存」の3画面で進めます。ストップウォッチ、手入力のどちらも利用できます。
3. 「この記録を保存する」を押し、「記録を保存しました」を確認します。
4. 「記録を見る」から一覧・詳細の確認、測定CSV・印刷可能なレポートの出力ができます。
5. 統合や詳細分析は、ホーム下の「取込・出力／担当者メニュー」から開きます。測定取込・CSV取込・統合CSV・AI分析用CSV・統合レポートを利用できます。

入力途中で画面内を移動しても、ホームの「続きから入力する」で戻れます。測定中の時計も継続します。「文字を大きく」で文字サイズを切り替えられます。担当者メニューは操作を整理するための分類で、追加のアクセス権限ではありません。

ログイン・保存には通信が必要です。通信が切れた場合は画面を閉じず、再接続して「今すぐ保存」を押してください。共通アカウントで複数の端末が同時編集した場合は、上書きを防いで保存を停止します。案内にあるバックアップを保存し、担当者が再ログイン・CSV取込で調整してください。端末のlocalStorageやサービスワーカーには個人データ・パスワード・認証トークンを保存しません。

## 写真

ホーム・ログイン画面にNUWA RoboticsのKebbi公式宣材写真を使用しています。掲載元・画像URLは `assets/CREDITS.txt` に記載しています。ジェネラス施設で撮影した写真ではありません。

## 認証とデータ保護

- GitHub Pagesは個人情報を含まないアプリコードを配信します。
- Supabase東京リージョンが認証とデータ保存を担当します。
- データAPIは毎回、検証済みユーザー、サーバーセッション、有効な職員アカウントを確認します。
- 一般のAuth新規登録はDBトリガーで拒否します。管理APIで発行したアカウントだけを許可します。
- 全テーブルでRLSを有効化し、anon/authenticatedへの直接アクセス権を削除しています。Edge Function内部だけがサービス権限を利用します。
- アカウントの測定・統合データは本人に限定します。共有操作した測定CSVは有効な職員アカウント間で閲覧・統合できます。
- 職員アカウントの停止は次回APIリクエストから反映します。画面は60秒ごとにも有効性を確認します。
- ソースマスターの空欄、原表、役割表は保持します。正式IDの空欄や職員表間の対応は推測して補いません。

## ソース構成

`index.html`、`app.js`、`app.css`: 統合画面・認証・アカウント保存。
`modules/`: 測定、統合、CSV、レポート処理。
`backend/`: データベース定義と認証API。データや秘密鍵は含みません。

Supabaseの公開可能キーはブラウザ接続用で、データアクセス権限を持ちません。サービスキー、共通アカウントの配布資料、原Excelは公開禁止です。

## AI連携

統合画面からAI分析用CSVを出力できます。機械判読用の列名、型、単位、出典、品質フラグ、欠損値の扱いは同梱の `AIデータ仕様.json` を参照してください。AIへの自動送信・解析は本アプリでは実行しません。AI用CSVも利用者IDなどを含むため、送信先を確認した上で別途解析してください。

## 保守

`backend/schema.sql` は初期セットアップの再現用です。運用中DBに重複適用しないでください。認証API `backend/api.ts` は外部ライブラリを使用せず、Supabase AuthとPostgRESTを利用します。フロントは同梱のPapaParse 5.4.1 / Chart.js 4.4.1を使用しています。
